Place free 3D assets in this folder.

Supported formats: .glb, .gltf, .obj

Name files with the object name so JARVIS can find them automatically, for example:
- coin.glb
- pen.obj
- iron_man_helmet.glb
- pizza.glb
- computer_interior.glb
- spider_man_mask.glb
- spider_symbol.glb

You can also pass an explicit model_path to create_3d_hologram.
Use assets you are licensed to use.
